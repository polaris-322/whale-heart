# 🐳 鲸鱼心的工作台 v2

一个梦幻卡通风格的移动端个人全能工作台，纯前端单页应用（PWA），支持添加到手机桌面离线使用。

## ✨ 核心特性

- 🎨 **6 套主题色自由切换**：粉蓝、紫橙、薄荷、日落、薰衣草、海洋
- 📱 **手机优先**：原生适配 390px 移动端，支持触屏
- 📲 **可添加到桌面**：完整 PWA，离线可用，像 App 一样启动
- 💾 **数据自动持久化**：所有数据保存在 localStorage，刷新不丢失
- ⏰ **每日自动更新**：每日 9:00 自动刷新选题/视频/理财报告等数据
- 🔀 **模块自由排序**：14 个模块侧边栏切换，长按拖动可调整顺序
- 🔒 **纯前端运行**：无后端依赖，保护隐私

## 🚀 使用方法

### 本地预览

由于 PWA 的 Service Worker 必须在 HTTP(S) 协议下运行，直接双击 `index.html` 打开**不会**触发添加到桌面功能。需要部署到静态服务器。

```bash
cd whale-heart
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

### 部署到公网（推荐）

把整个 `whale-heart` 文件夹拖到 [Vercel](https://vercel.com)、[Netlify](https://netlify.com) 或 [Cloudflare Pages](https://pages.cloudflare.com) 部署，自动获得 HTTPS，手机即可访问并添加到桌面。

### 安装到手机桌面

- iOS Safari：分享 → 添加到主屏幕
- Android Chrome：菜单 → 添加到主屏幕 / 安装应用

## 🎨 主题色切换

点击侧边栏最下方的 **⚙️ 设置** 按钮，可在 6 套配色中自由切换。切换后全局按钮、进度条、强调色、渐变背景会实时变化，选择自动保存。

## ⚠️ 数据说明

### 关于"真实数据"

由于本项目是纯前端静态应用，未接入任何第三方付费 API（保护隐私和避免跨域问题），因此以下模块使用**基于日期种子的模拟数据**：

- 选题灵感：爆款视频池 / 选题灵感池，每日随机抽取，内容贴近真实赛道
- 理财助手：指数、板块、基金代码、早晚报均为模拟数据，仅供练习和规划参考，**不构成投资建议**
- 就业导航：招聘信息为示例数据，实际求职请以官方渠道为准
- 论文阅读：AI 回复基于内置学术知识库匹配，复杂问题建议结合专业工具

如需接入真实平台 API（抖音/小红书/股票接口/招聘网站等），需要额外开发后端代理服务并处理各平台授权。
